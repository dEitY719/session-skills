끊긴 세션의 TodoList 를 받아 재개 대상과 잘게 쪼갠 실행 계획을 생성합니다.

3

결과

이 문서는 실제 실행 기록이 아니다 — 실행하지 않았다

사유 1 (자기참조). restart 는 “끊긴 작업을 이어서 재개” 하는 스킬이라, 지금 호출하면 진행 중인 이 문서화 작업 자체를 재개 대상으로 잡아 덮어쓴다.

사유 2 (안전 계약). 이 repo 의 CLAUDE.md 와 SKILL.md 가 “user-triggered recovery, never a building block — 다른 스킬이나 흐름 안에서 호출 금지” 를 명시적 계약으로 두고 있다.

사용자와 합의해 미실행으로 남긴다. 아래는 실행 결과가 아니라 스킬이 정의한 출력 규격이다.

항목규격 (references/output-format.md)
시작재개 대상을 밝히는 announce 줄 — 조용히 건너뛰지 않는다
진행단계마다 무엇이 끝났는지 한 줄씩 보고
종료다음 구체 명령을 지목하는 Next: 줄 — 조용히 idle 로 돌아가지 않는다
대상 없음hard-stop 템플릿을 내고 사용자에게 묻는다

검증하려면

실제로 턴이 끊긴 세션에서 사용자가 직접 /session:restart 를 호출해야 한다. 이 스킬은 설계상 다른 무엇도 대신 호출할 수 없다.
