# schedule 사용 결과

> **한 줄 요약** — 명령 문자열과 지연 시간을 받아 one-shot 크론 잡을 생성합니다.

```
"/skill args" + M분  ──▶  /session:schedule  ──▶  [SCHEDULED] 확인 1줄 (job: <id>)
```

## 1. 실행한 명령

범용 형식:

```
/session:schedule [--time M] "<command>"
```

## 2. 입력

- `--time M` — 지연(분), 기본 5
- `<command>` — 발화 시점에 그대로 전달될 슬래시 명령 또는 자연어 작업

## 3. 결과

**이 문서는 실제 실행 기록이 아니다 — 실행하지 않았다.**

사유: 이 스킬의 유일한 산출물은 `CronCreate` 로 만드는 **실제 크론 잡**이다. 데모 목적으로
등록하면 예정에 없던 시각에 세션이 깨어나 임의의 프롬프트를 실행하게 된다. 부작용 없는
드라이런 모드가 스킬에 없어, 사용자와 합의해 미실행으로 남긴다.

`SKILL.md` Step 4 가 정의하는 확인 출력 형식은 다음과 같다:

```
[SCHEDULED] [M]분 후에 실행됩니다: <command>  (job: <returned-id>)
```

주의: Claude Code 밖에서는 `CronCreate` 가 없으므로 이 스킬은 **동작하지 않는다**.
그때의 올바른 동작은 "사용 불가" 를 말하고 멈추는 것이다 — `sleep` 이나 백그라운드 셸로
흉내내면 성공을 보고하고 실제로는 아무 일도 일어나지 않는다.
