실행한 명령

범용 형식:

/session:worktree-spawn [--ai <name>] [--task <slug>] [--base <ref>] [<branch>]

왜 별도 저장소에서 실행했나

이 repo 의 작업 디렉터리는 이미 워크트리(wt/feat/1) 라서 스킬의 Step 1 이 정상적으로 차단한다. 해피 패스를 보이기 위해 scratchpad 에 독립 테스트 저장소(bare origin 포함)를 만들고 references/bash-commands.md 의 Step 1~8 을 그대로 실행했다.

2

입력

메인 저장소

<scratchpad>/wt-demo
브랜치 main, 커밋 513f9f1

원격

<scratchpad>/wt-demo-origin.git (bare)

환경

CLAUDECODE=1
AI_AGENT_NAME 미설정

3

결과

Step 8 실제 출력:

[OK] Worktree ready
  Path:   <scratchpad>/wt-demo-claude-1
  Branch: wt/claude/1
  Base:   origin/main
  Teardown: git push -u origin wt/claude/1 && git worktree remove <path> && git branch -d wt/claude/1

단계별 실제 해석값:

단계결과
Step 1git-dir == git-common-dir → 워크트리 아님, 통과
Step 1.5GIT_CRYPT_ACTIVE=false → bypass 경로, 플래그 없음
Step 2AGENT=claude — 우선순위 3 ($CLAUDECODE=1)
Step 3NEXT_INDEX=1 — 기존 wt-demo-claude-* 없음
Step 4BRANCH=wt/claude/1 — 인자 없음 경로
Step 5BASE_REF=origin/main — 우선순위 2

Step 7 이 남긴 로그 1줄:

[2026-09-01T17:02:31+0900] SPAWN project=wt-demo agent=claude index=1
  path=<scratchpad>/wt-demo-claude-1 branch=wt/claude/1 base=origin/main
